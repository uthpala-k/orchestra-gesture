# V1.1 real-audio replacement

This patch replaces the experimental synthesized folk voices and synthesized
Orchestral Pulse with real sample playback.

## New sample install command

```powershell
npm run install:folk-samples
```

It installs a small pitch subset of real FluidR3_GM samples:
- Whistle
- Pan Flute
- Recorder
- Ocarina
- Harp
- Dulcimer
- Accordion / Musette

## Real Orchestral Pulse

Run the VSCO importer again:

```powershell
npm run import:samples
```

The importer now creates:
- sample-manifest.json — sustained orchestra
- pulse-manifest.json — short rhythmic articulations

Orchestral Pulse uses real sampled violin, viola, cello, horn, harp and
timpani where the 256 pack contains suitable files. No oscillator beep layer
is used for the pulse.

## Run

```powershell
npm install
npm run import:samples
npm run install:solo-samples
npm run install:folk-samples
npm run dev
npm run build
```
