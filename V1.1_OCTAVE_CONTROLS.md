# Orchestra / Gesture V1.1 — octave-control amendment

This is an amendment to V1.1; the website/package display remains V1.1.

Changes:
- Four independent Melody octave controls (Index/Middle/Ring/Pinky).
- Range: -2 to +2 octaves.
- Whistle, Pan Flute, Recorder and Ocarina default to +1 octave.
- Octave shift works in SNAP and GLIDE.
- Note readout reflects the sounding octave.
- Instrument dropdowns show names only.
- About, User Guide, README and V1.1 refinement documentation updated.
