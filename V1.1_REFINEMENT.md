# V1.1 refinement — sustain, per-voice volume, final master mix

Changes:
- Real sampled sustaining folk voices refresh while SNAP pinch is held:
  Whistle, Pan Flute, Recorder, Ocarina, Musette.
- Plucked voices such as harp and dulcimer still decay naturally.
- Settings -> Melody now has per-voice Volume (0-150%) beside Reverb.
- Settings -> Sound defaults:
  Orchestra mix = 15%
  Solo mix = 70%
- Orchestra/Solo mix sliders now act as literal final bus output faders.
- Existing stronger real-sample Orchestral Pulse arrangement is retained.

Replace the files from this patch over the current V1.1 project, then run:

npm run dev

Test locally before building/pushing.

Documentation sync:
- User Guide documents the final V1.1 Melody/Sound behavior.
- README documents the final V1.1 refinement.
- About credits FluidR3_GM via midi-js-soundfonts and lists both attribution files.

- Instrument dropdowns now show only clean instrument names.
- Whistle, Pan Flute, Recorder and Ocarina use a recommended +1 octave default.
- Each of the four Melody finger slots now has Octave −/+ controls from −2 to +2.
- The selected octave applies in both SNAP and GLIDE and the note readout follows
  the actual sounding register.
- Website About, User Guide and README are amended while the visible release
  remains V1.1.
